# Inspeção Visual de Peças de Fundição Metálica

Mini-projeto de visão computacional e CNN para classificação binária (OK vs defeituosa).

## Ambiente e dependências

- Python 3.10+  
- Pacotes em `requirements.txt` (TensorFlow, OpenCV, NumPy, Matplotlib, gdown, Jupyter)

```bash
python -m venv .venv
pip install -r requirements.txt
```

## Dataset

Coloque as imagens em:

```text
casting_data/
  def_front/
  ok_front/
```

Ou use o download do Google Drive previsto na Sprint 1 do notebook.
